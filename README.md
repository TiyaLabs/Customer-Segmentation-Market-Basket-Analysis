## Overview

This project combines Customer Segmentation and Market Basket Analysis to help marketing teams better understand customer behavior and create more targeted promotional strategies.

## Key Features

* Data preprocessing and feature engineering
* Principal Component Analysis (PCA)
* K-Means Clustering
* Hierarchical Clustering
* Market Basket Analysis using Apriori
* Customer segmentation profiling
* Product bundling recommendations

## Results

Three customer segments were successfully identified:

* Regular Customers
* Active Digital Users
* Premium Active Customers

The project also discovered several strong product associations that can be used for cross-selling and bundling strategies.
